# odin-recipes

Recipe Website Project

This project is a simple recipe website built with three separate pages, each dedicated to a different recipe. The goal was to practice structuring web pages, organizing content, and creating a consistent layout across multiple pages.

Each recipe page includes all the essential elements: a title, an image of the dish, a short description, a list of ingredients, and step-by-step preparation instructions. The layout and structure are consistent across all pages, making the site easy to navigate and visually coherent. One of the pages was used as a reference (steak recipe), and the others were built to match the same design and format.

The project demonstrates basic HTML skills such as using headings, paragraphs, lists, images, and links. It also focuses on writing clear and accessible content, including proper image alt descriptions. Overall, it’s a complete beginner-friendly project that showcases how to build and organize a small multi-page recipe website.
